<h2>🚀 What is cybercrew-ip-scanner?</h2>

<p>cybercrew-ip-scanner is a fast, portable tool that helps you scan your network for IP addresses and open ports. It's designed for <strong>Vulnerability Assessment and Penetration Testing (VAPT)</strong> but is simple enough for anyone to use. Whether you're a security professional, a network administrator, or just curious about your home network, this tool gives you powerful scanning capabilities in a single file.</p>

<p>This software comes as a single binary file for <strong>Windows, Linux, and macOS</strong>. No installation required. No complicated setup. Just download and run.</p>

<h2>✨ Key Features</h2>

<ul>
  <li>🔍 <strong>IP Scanning</strong> - Discover all devices on your network quickly</li>
  <li>🔌 <strong>Port Scanning</strong> - Check which ports are open on any IP address</li>
  <li>📋 <strong>Banner Grabbing</strong> - Identify services running on open ports</li>
  <li>🖥️ <strong>NetBIOS Scanning</strong> - Gather information about Windows machines on your network</li>
  <li>📦 <strong>Portable</strong> - Single file, no installation needed</li>
  <li>⚡ <strong>Fast Performance</strong> - Scans entire subnets in seconds</li>
  <li>🎨 <strong>User-Friendly Interface</strong> - Built with PyQt6 for a clean, modern look</li>
  <li>🔄 <strong>Cross-Platform</strong> - Works on Windows, Linux, and macOS</li>
</ul>

<h2>📊 Understanding Results</h2>

<p>The scanner shows you:</p>
<ul>
  <li><strong>IP Address</strong> - The device's network address</li>
  <li><strong>Port Number</strong> - The specific port that's open</li>
  <li><strong>Service Name</strong> - What service is running (e.g., HTTP, SSH, FTP)</li>
  <li><strong>Banner Information</strong> - Additional details about the service version</li>
  <li><strong>Status</strong> - Whether the port is open, closed, or filtered</li>
</ul>

<h2>🆘 Troubleshooting</h2>

<h3>App won't start</h3>
<ul>
  <li>Make sure you downloaded the correct version for your operating system</li>
  <li>Try running as administrator (right-click > Run as administrator)</li>
  <li>Disable antivirus temporarily and try again</li>
</ul>

<h3>No results found</h3>
<ul>
  <li>Check your network connection</li>
  <li>Make sure you entered the correct IP range</li>
  <li>Try increasing the timeout setting</li>
  <li>Disable your firewall temporarily</li>
</ul>

<h3>Slow scan</h3>
<ul>
  <li>Reduce the port range</li>
  <li>Increase the timeout value</li>
  <li>Close other applications using the network</li>
</ul>
